# shadowverseNEO

オンライン対戦のブラウザカードゲームです。

## ディレクトリ構成

- `server.js`: サーバー起動用のエントリーポイント。Express と Socket.IO を起動し、静的ファイルを配信する。
- `src/gameServer.js`: サーバー入口。Express の起動と `registerSocketHandlers` の呼び出しを担当する。
- `src/socketHandlers.js`: 各 Socket イベントの受信処理をまとめたファイル。部屋作成、参加、デッキ設定、カード使用、攻撃、進化、ターン終了などを管理する。
- `src/roomState.js`: ルーム状態、プレイヤー状態、デッキ、手札、場、ロギング、スナップショット生成、効果音イベントの送信を担当する。
- `src/gameData.js`: カード定義とデッキ生成。カード一覧、シャッフル、20枚デッキの制約、ランダム構築ロジックを持つ。
- `src/cardEffects.js`: フォロワー召喚時とスペル使用時の効果処理。回復、ダメージ、召喚効果をまとめて管理する。
- `src/attackLogic.js`: 攻撃計算用のロジック。攻撃側と守備側のダメージ計算を分離し、攻撃解決を簡潔に扱う。
- `public/index.html`: 画面レイアウト。ロビー、デッキ構築、対戦場、効果確認パネル、ログ、再戦ボタンなどを定義する。
- `public/css/styles.css`: UI とゲーム画面の描画スタイル。カード、戦場、ボタン、モバイル横画面表示などの見た目を管理する。
- `public/js/app.js`: クライアント側の描画とアクション処理。状態受信、カード選択、攻撃、進化、再戦リクエストなどを処理する。
- `public/js/audio.js`: BGM と SE の再生制御。ホーム画面BGM、戦闘BGM、効果音の再生とロック解除を管理する。
- `public/js/deckState.js`: デッキ構築用の状態管理。選択中デッキの配列化、カード追加・削除、デッキ数の管理を担当する。
- `public/audio/`: 効果音・BGM 音声ファイルの保存先。カード召喚、攻撃、進化、回復、スキル使用などの音源を格納する。

## 変更意図

- カードの内容やバランスを `src/gameData.js` で集中管理する。
- サーバー処理は `src/socketHandlers.js` と `src/roomState.js` に分離し、単一ファイル肥大化を防ぐ。
- カード効果の計算は `src/cardEffects.js` と `src/attackLogic.js` に分離し、ルールの修正がしやすい構成にする。
- 画面表示は `public/index.html` と `public/css/styles.css` に整理し、見た目と構造を分離する。
- フロントエンドの動作ロジックは `public/js/app.js` で扱い、音声やデッキ状態を別ファイルに分けて可読性を上げる。
- 効果音は `public/js/audio.js` と `public/audio/` に分離し、再生条件を簡単に変更できるようにする。

## 補足

- ルーム作成後はデッキ構築 → 対戦開始の流れを採用している。
- デッキの枚数は 20 枚固定で、21 枚目を引くと敗北条件になる。
- 再戦時にはデッキ構築画面に戻る設計を採用している。
- 対戦中の効果音は両プレイヤーへ同時配信されるようにしている。

これにより、各項目を独立して編集しやすく、今後の拡張やデバッグがしやすくなっています。
